## 🛠️ Installation Steps

### Step 1️⃣ APK Download
- Link खोलो
- **Download** button दबाओ
- APK download होगा (~ 5-10 MB)

### Step 2️⃣ Security Settings Enable करो
```
Settings → Security → 
Unknown Sources → ON
```

### Step 3️⃣ APK Install करो
- **Files** या **File Manager** खोलो
- **Downloads** folder में जाओ
- **app-release.apk** पर tap करो
- **Install** दबाओ

### Step 4️⃣ Play करो! 🎮
- Installation complete होने का wait करो
- **Open** दबाओ
- **Political Simulator** खेलो!
