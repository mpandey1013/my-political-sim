## Troubleshooting

### "Installation blocked" Error
1. Settings खोलो
2. Security → Unknown Sources → **ON** करो
3. फिर से install करो

### App नहीं खुल रहा
1. Phone restart करो
2. APK delete करो
3. फिर से download और install करो

### APK download नहीं हो रहा
- Browser change करो (Chrome, Firefox, etc.)
- WiFi का use करो
- VPN try करो
